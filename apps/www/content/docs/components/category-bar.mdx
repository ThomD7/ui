## About

The category bar component is a horizontal bar that displays a list of categories. It is used to filter content based on the selected category.

## Usage

```tsx
import { CategoryBar, CategoryBarItem } from "@/components/ui/category-bar"
```

```tsx
<CategoryBar>
  <CategoryBarItem>Category 1</CategoryBarItem>
  <CategoryBarItem>Category 2</CategoryBarItem>
  <CategoryBarItem>Category 3</CategoryBarItem>
</CategoryBar>
```
